## 2. Что делает Солана (по шагам)

Рабочая папка: `/Users/v1tush/hackaton-cu-2026`. Данные уже на месте: `dataset/` = 1.3 ГБ, 3604 файла (`real/train` 263, `synth/train` 600, `real/test` 137). Python 3.13, пакеты не стоят, GPU CUDA нет — всё считаем на CPU.

### Шаг 1. Среда
```bash

source .venv/bin/activate

python -c "import numpy, pandas, cv2, sklearn, catboost; print('ok')"
```

### Шаг 2. Единый сплит по `object_id`
Загрузить `dataset/labels/real_train.json` (263 кадра, 214 аннотаций) и `dataset/labels/synth_train.json` (600 кадров, 678 аннотаций). Собрать все `attributes.object_id`, отсортировать, `val_objects = set(objects[::5])` — как в 4-й ячейке `baseline.ipynb`. В val попадает кадр/аннотация, у которой есть объект из `val_objects`. Сохранить `work/split.json`, напечатать счётчики и проверить отсутствие пересечений. **Все шаги дальше используют только этот сплит**, включая синтетику.

### Шаг 3. Crops и признаки
Для каждой аннотации наложить `segmentation` на `color.png` (в `real/train` нет `mask.png` — маска строится из полигона; в `synth/train` есть `mask.png`, но берём полигон для единообразия), вырезать bbox с паддингом 10%, ресайз 128×128 → `work/crops/{train,val}/{material}/{image_id}_{ann_id}.png`.

Собрать `work/features.csv`: `split, image_id, ann_id, object_id, form, material, volume_ml, mass_g, take` плюс признаки:
- цвет: mean/std RGB и HSV, гистограммы H(18)/S(8)/V(8);
- глубина: доля нулевых пикселей в маске, высота над полом (плоскость из `meta.json`, как в `raw_volume_ml`), перепады соседних пикселей;
- форма: aspect ratio, площадь маски, доля маски в bbox.

### Шаг 4. Классификатор материала (+16.6)
Обучить на train: `LogisticRegression` + `StandardScaler`, затем `CatBoostClassifier`. Метрика — `balanced_accuracy_score` на val (это M). Лучшую модель → `work/material.pkl`, напечатать classification report и confusion matrix. Цель **M ≥ 0.5** (было 0.17). Если M < 0.5 — не выдумывать, запросить у Гриши эмбеддинги CLIP/DINO и повторить с linear probe.

### Шаг 5. Калибровка объёма (+9.5)
Скопировать `raw_volume_ml` из 9-й ячейки `baseline.ipynb`. Для train посчитать `raw`, построить таблицу raw vs `volume_ml` по `form × material`, медианный коэффициент `true/raw` + общий fallback + clip. Отдельно случай «глубины нет» (стекло, блестящий металл) — брать медиану группы. Метрика V из `score.py`: `max(0, 1 - |ln(pred/true)|/ln 3)`, обнуляется при ошибке ≥3×. Цель **V ≥ 0.8**.

### Шаг 6. Прямой классификатор `take` (+8.7)
Бинарный классификатор на признаках шага 3 + калиброванный объём + оценка массы (`densities.csv`). Заменить правило «масса ≤ 500 г». Метрика S — среднее accuracy отдельно по `take=0` и `take=1`. Цель **S ≥ 0.75**.

### Шаг 7. Чистые замеры (важно!)
Построить `work/val_oracle.csv`: для val-кадров взять **истинные рамки** из разметки, а материал/объём/`take` — свои. Строка: `x1 y1 x2 y2 1.0 form material volume mass take` (10 значений), пустые кадры — `none`. Прогнать:
```bash
python score.py check --labels dataset/labels/real_train.json --submission work/val_oracle.csv
```
D будет ≈1.0, поэтому так видны **чистые M/V/S** без влияния детектора. Результат → `ЖУРНАЛ.md`.

### Шаг 8. Интеграция
В `predict()` заменить `MATERIAL_GUESS` на `material.pkl`, `volume` на калиброванный, `take` на классификатор. Пересобрать val-предсказания уже с YOLO и снова `score.py check`. **Оставлять только изменения, повысившие Score на локальной валидации.**

### Шаг 9. Финал
Сгенерировать `submission.csv` на 137 кадров `real/test`, записать D/M/V/S в `ЖУРНАЛ.md`, после восстановления сайта отправить. В финал — 2 лучшие по локальной валидации версии. Финальный ноутбук должен запускаться с нуля (Run All).
