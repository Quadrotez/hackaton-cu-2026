# Астрамис — Научная орбита 2026

Командный репозиторий кейса **Astramis: Что под щёткой?** (хакатон Центрального университета, 20–22 ноября 2026).

Страница соревнования: https://stackmorelayers.ai/competitions/astramis

## Что здесь

- `BRIEF.md` — полная рабочая памятка: условие, формат сабмита, метрика, правила, план.
- Данные, бейзлайн и метрика лежат **на платформе** во вкладках «Данные» и «Код» — в репозиторий не кладутся (по правилам хакатона данные кейса не выкладываются в открытый доступ).

## Быстрый старт

1. Открыть соревнование → вкладка «Код» → ноутбук бейзлайна → «Открыть в среде».
2. Включить GPU (T4), прогнать все ячейки → получить `submission.csv`.
3. Вкладка «Отправить решение» → загрузить CSV → посмотреть балл на публичной части.
4. Дальше улучшать по одному шагу и проверять локально через `score.py`.

Дедлайн: **22 ноября 13:00 мск**. 10 отправок в день, 2 решения в финальный зачёт.

## Правила

- Инференс на тесте — без интернета, облачные модели и LLM с картинками нельзя.
- Открытые предобученные веса можно, источник назвать в обсуждении соревнования.
- ИИ-помощники для кода разрешены; на защите надо объяснить любую часть решения.
- Валидацию делить по `object_id`, не по кадрам: в тесте предметы новые.
- Финальное решение — один воспроизводимый ноутбук/скрипт.
