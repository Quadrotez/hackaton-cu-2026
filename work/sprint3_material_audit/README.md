# Первый фиксированный аудит metal ↔ plastic

## Протокол до запуска

Сравниваем три состояния на неизменённых пяти `detector_folds_v1`:

1. Точный frozen `bulk_y_bottom` OOF, SHA-256 `f0eb64df263afff0130b4e4daf19591031e0f9092374fb9fa6eef1882f1e807e`, ожидаемый Score `72.78019593033471`.
2. `rgbd_no_jitter` — новая бинарная голова с пятью идентичными копиями исходного train-кропа.
3. `rgbd_jitter` — та же голова, тот же исходный train-кроп; четыре остальные копии заменяем четырьмя фиксированными RGB/масочными вариациями. Именно **3–2** оценивает вклад расширения, **2–1** — вклад замены головы без расширения.

Фиксированная L2 logistic regression (`C=1`) со взвешенным стандартизатором. Каждый класс получает половину веса, каждый объект внутри класса — равный вес, каждый кадр внутри объекта и каждая из пяти копий внутри кадра — равный вес; вес каждого исходника и суммарный вес каждого объекта абсолютно одинаковы в control и augmented. Сумма весов при fit равна числу train-объектов. Переключаем только если frozen material уже из пары, полная модель даёт противоположному классу ≥0.85, и **все** модели, обученные с удалением по одному train object, дают ему ≥0.70. Нет сетки порогов, подбора на outer val, выбора лучшей абляции или обучения на outer OOF прогнозах. Предварительный критерий продолжения для augmented: положительный pooled delta относительно frozen, без регрессии ни на одном фолде.

Только реальный train RGB и depth: сатурация/интенсивность/блики, градиенты внутри маски, доли дыр глубины и локальные остатки глубины. Разметка локализует только *train* кропы и задаёт train target; для val — исключительно предсказанные маски n640 именно своего OOF-fold и неизменная привязка l960-гипотез к донору. Координаты боксов, поля аннотаций (включая geometry/size/mass/form), ID/метаданные/пути и метки val не входят в модель; `object_id` используется для разделения, веса и jackknife. Frozen material используется только как gate, а не как feature. `Usage` не участвует; метрика оценивается только после формирования всех прогнозов. Synthetic доступен, но не использован: те же физические ID, смещение RGB/Depth при симуляции могло бы смешать эффект jitter с изменением домена. Данные test не читаются.

Из корня репозитория, с локальным окружением:

```sh
set -o pipefail
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B work/sprint3_material_audit/run.py \
  --out work/sprint3_material_audit/run01 2>&1 | tee work/sprint3_material_audit/run01.log
```

Для повторного запуска используйте новое имя `--out`. Выход: `report.json` со всеми компонентами, двумя confusion-матрицами (GT metal/plastic × predicted metal/plastic/other/miss) и двунаправленным churn (включая unmatched, fixed, broken, still wrong, distinct frames и donors); CSV вероятностей для каждого eligible OOF-донора; два полных OOF JSON. `report.json` содержит SHA входов, исходника и версии библиотек.

Обе головы: Score **72.6947**, `M` 0.661919 → 0.657646, `D/V/S` без изменений. Jitter сдвинул вероятности у 161 из 161 eligible доноров (максимальный абсолютный сдвиг 0.1883), но после фиксированного правила OOF JSON побайтово одинаковы. У каждой головы 4 переключения `plastic→metal` в трёх кадрах: 2 испорченных GT-совпадения, 2 unmatched, 0 исправлений; `metal→plastic` отсутствует. Hits metal 8/38 без изменений; plastic 51/78 → 49/78. Отрицательный эффект относительно frozen относится к замене головы, а не к jitter; предзаданный критерий продолжения не пройден. Test-экспорт не выполнялся. Локальных ресурсов хватило.
