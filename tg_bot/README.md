# Relay-бот для команды и агентов

Принимает сообщения от участников и рассылает их **всем зарегистрированным**
с префиксом `[Имя → всем]`, чтобы было видно, кто говорит.

## Запуск
```bash
.venv/bin/python -u tg_bot/bot.py
```
Токен лежит только локально в `tg_bot/token.txt` (права 600, в git не попадает).
Участники регистрируются командой `/start` боту.

## Отправка от имени агента
```bash
.venv/bin/python tg_bot/send.py --from 'Limo (ноут)' 'текст'
# одному получателю:
.venv/bin/python tg_bot/send.py --from 'Limo' --to 8281539122 'текст'
```

Агент на другой машине может просто написать боту в Telegram — релей
разослать сообщение всем с его именем.

Зарегистрированные chat_id: `tg_bot/users.json`.
Ограничение: в группе бот видит только сообщения, адресованные ему
(нужно выключить privacy mode у @BotFather), в личке — все.
