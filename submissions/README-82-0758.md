## Replay

From the repository root with the original local artifact layout:

```sh
PYTHONPATH=work/astra_clip_packages:work/astra_packages:work:fusion:. \
  work/venv_yolo/bin/python -B fusion/final_detector_benchmark.py \
  --device mps --build-test --out work/sprint10_kaggle_retrain/replay_82_0758
```

The benchmark fits DINO heads only on real training boxes inside each fold.
The encoder architecture, RGB crop and normalization, and linear probe recipe
follow DINO notebook revision `ff78a8cc93ca262fa6406b797121152d048f8382`;
the frozen Sprint 5 adapter applies its `both` rule. Expected Score uses the
unmodified gated volume and original/flip DINO and CLIP features of predicted
mask donors, with the fitted fold or test policy.

This branch preserves the code, fold configuration and reports, not the
private RGB-D dataset, model checkpoints, raw detector caches, frozen OOF/test
intermediates or generated training scenes. A full rerun requires those local
artifacts, including the original A/B exports and Targeted B staging manifest
for the comparison arms. No Kaggle credentials are included.
