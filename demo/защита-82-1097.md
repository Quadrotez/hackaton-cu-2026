## Какой код лежит в ветке

- `gen_submission/gen_model.ipynb` — полная ячейка для DINO-признаков и двух линейных моделей на **готовых** кропах и манифестах; на выходе два CSV вероятностей. Изначальные `.npy` читаются только по первым трём каналам. Сгенерированные RGB-кропы добавляются к обучению материала во всех фолдах; происхождение добавки и отсутствие пересечений не доказаны.
- `dino/README.md` описывает передачу вероятностей в `fusion/sprint5_crop_adapter.py`: локальная оценка, выбор варианта, сборка финального CSV с замороженной базой. Сам адаптер, исходные веса детектора, готовые кропы и архив сгенерированных входов не входят в дерево выбранного коммита. `train_and_submit.py` — отдельный ранний скрипт, не генератор результата 82,1097. Запуск с нуля без внешних артефактов не подтверждён.
- `score.py` — расчёт метрики: D — mAP по форме при IoU 0,5; M — усреднение по классам материала; V — штраф за логарифм отношения объёмов, при ошибке в три раза и выше ноль; S — усреднение по лёгкой и тяжёлой группам. Реальная масса нужна для определения группы, заполненная в предсказании масса напрямую в метрику не входит.

## Исходник и повторный экспорт

Редактируйте `presentation-source/build-defense.py` для синхронного обновления HTML и PPTX. Пять пользовательских фонов, кадрированных до 16:9, лежат в `assets/defense-backgrounds/` и встраиваются в оба формата, поэтому HTML открывается отдельным файлом. Для PDF передайте путь к Chrome или Chromium:

```bash
python -m pip install python-pptx
python demo/presentation-source/build-defense.py --chrome "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

Без аргумента `--chrome` обновятся HTML и PPTX. Для ручного экспорта из HTML используйте «Печать». Старые версии презентации в `demo/` не относятся к этому комплекту.
