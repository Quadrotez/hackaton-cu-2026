# Дизайн презентации: Liquid Glass + палитра «Научной орбиты»

Два варианта одной и той же презентации:

| Файл | Фон |
| --- | --- |
| `index.html` | Техническая «орбитальная» сетка: тонкая решётка, точки, медленно вращающиеся орбиты и геометрические акценты. **Не градиент.** |
| `index-optic.html` | Оптическая иллюзия: вращающаяся спираль, радиальные лучи и прямые линии Херинга, которые кажутся изогнутыми. |
| `index-trip.html` | Психоделический режим: калейдоскоп с анимированной турбулентностью и сдвигом оттенка; поверх всех слоёв появляются чёрно-белые полупрозрачные лица в круглых масках из `faces/`, их можно вытолкнуть за экран. Они исчезают за 3–4 секунды. |

Содержимое слайдов, объект `RESULTS` и управление одинаковы во всех файлах.

## Сравнение с Apple Liquid Glass

Источники принципов: [Liquid Glass Design — guide](https://liquidglassdesign.com/what-is-liquid-glass),
[разбор анатомии кнопки](https://liquidglassdesign.com/blog/liquid-glass-button),
[Apple HIG](https://developer.apple.com/design/human-interface-guidelines/).

| Принцип Apple | Как реализовано | Насколько близко |
| --- | --- | --- |
| Материал преломляет фон, а не только размывает | SVG `feTurbulence` + `feDisplacementMap` в `backdrop-filter` (`#lens-refract`) | Ближе обычного glassmorphism, уступает WebGL-шейдерам |
| Блик реагирует на движение | Радиальный блик за курсором (`--mx`, `--my`) + медленный пробег `.sheen::after` | Приближение «наклона устройства» |
| Хроматический край | `conic-gradient` + `mask-composite`: янтарный → циан → фиолет → лайм | Видно на кромке слайда |
| Толщина стекла | Внутренние тени `inset 0 2px 0`, `inset 0 -22px 50px` и мягкая внешняя | Близко по ощущению «слитка» |
| Контраст текста | Белый SF Pro с `text-shadow`, затемняющий подтон внутри стекла | Соответствует главному правилу HIG |
| Стекло только на одном слое | Сцена — одно стекло; карточки — полупрозрачные подложки с волосяной границей | «glass on glass reads as a demo» |
| Доступность | `prefers-reduced-motion` выключает вращение орбит и иллюзии | Базовая поддержка |

WebGL-шейдер с RGB-дисперсией сознательно не использован: SVG-фильтр работает офлайн и из `file://` без сборки.

## Как смотреть

Открой любой из двух HTML-файлов в Safari или Chrome в полноэкранном режиме.
`←` / `→` — слайды, `P` — печать в PDF. В варианте с иллюзией стекло тоньше, чтобы муар был виден сквозь него.

## Скримеры Trip

Три чёрно-белых варианта крупного лица появляются на всех слайдах через случайные интервалы 5–9 секунд и исчезают через 0.95 секунды. Меню «Показ» позволяет отключить их или запустить вручную. В экспортном режиме и при паузе эффектов они не появляются.
